Part 1 - Brain

TL;DR

The cat-feel does not live in the locomotion layer and it does not live in the skill library. It lives in a small thing on top: a behavioral-mode attractor with a 6-dimensional mood latent and a stochastic decision period. Add those three to a vanilla PPO categorical head and a generic walker, and the rollout starts to look like a cat.

This page summarizes Part 1 — Brain. It also describes the substrate the brain runs on (Tier 1 walker, Tier 2 skills) and documents the paradigms we tried and threw away.

The stack

brain (Tier 3) — PPO + 6-D mood + 6-mode attractor, ~0.5 Hz ↓ skill ID skills (Tier 2) — { walk, crouch, lie_belly, stay } + scripted get_up ↓ velocity / joint targets motion (Tier 1) — Go1 velocity-tracking walker (mjlab PPO), 50 Hz ↓ joint torques MuJoCo + Unitree Go1

Each tier is independently trainable. The contribution of Part 1 is the brain layer plus the empirical observation that the skill set should be small — four learned skills is enough, more skills do not help.

Why three pieces, specifically

attractors A low-frequency mode-transition policy picks one of six behavioral modes (resting, observing, stalking, playing, grooming, exploring). Each mode exposes a coherent subset of skills via an action mask. Without this, the brain thrashes between skills every tick.

mood A 6-vector Ornstein–Uhlenbeck latent. Three of its dimensions, passed through a sigmoid, are the weights on the curiosity / comfort / play reward streams. Behavior shifts gradually rather than discretely — a sleepy cat takes minutes to become a playful one.

stochastic decision period The brain is consulted every T ~ U(1.5, 4.0) s, not on a fixed clock. This single change eliminates the metronomic 2 Hz switching pattern that a fixed-tick categorical head produces, without any retraining.

Skill library

Four learned skills, one scripted recovery. Earlier versions of the system carried fifteen named skills; we converged here after the faking-is-enough principle: scripted PD for postures, RL only where RL is necessary.

walkGo1 mjlab velocity-tracking walker.
crouchStable crouch posture, 489-step episode.
lie_bellyBelly-down loaf pose.
stayFreeze current joint config.
get_upScripted PD keyframe sequence (not RL).
brain (composed)10-min autonomous rollout.

What we tried and removed

A paper that only reports the final design overstates how obvious that design was. These paradigms were tried, integrated, and removed:

AMP imitation track. Trained PPO + a style discriminator over ~20 retargeted cat motion clips. Under velocity commands, the resulting policy moved zero meters in five seconds. We moved cat-feel up to Tier 3.
walk-these-ways as a unified skill space. Forked the mjlab Go2-Flat task into a MoB variant with body-height, gait-frequency, and stance commands. Two consecutive runs failed to actually expose the new commands to the policy. We use separate skill checkpoints.
Single-policy RL get-up. Eleven variants (v1–v10 plus FR-Net auxiliary head). Eight converged to sphynx or belly-flat reward-hacks. One looked successful but only because of a curriculum-at-deployment bug. The final get_up is a 400-tick scripted PD keyframe and works on the first try.

Quickstart

git clone https://github.com/jeffrah00/robot-pet-cat.git
cd robot-pet-cat
python3.11 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"

# Download released weights (~5 MB total)
python scripts/download_weights.py

# Run a 30-second autonomous rollout
python scripts/render_brain_3d.py \
    --checkpoint checkpoints/brain/brain_4skill_v1.zip \
    --duration 30 --output renders/demo.mp4
